Machine Learning with Python - IBM

Este repositório contém todos os laboratórios, exercícios práticos e o projeto final desenvolvidos durante o curso **"Machine Learning with Python"** oferecido pela IBM. 

O objetivo deste repositório é documentar o meu progresso e consolidar os conhecimentos adquiridos em análise de dados, modelagem preditiva e avaliação de algoritmos de Machine Learning.

Estrutura do Repositório:

*   **`/Labs`**: Contém os notebooks (`.ipynb`) com os exercícios práticos de fixação abordando regressão, classificação, clustering (agrupamento) e sistemas de recomendação.
*   **`/Final_Project`**: Contém o projeto final do curso. Nele, desenvolvi e comparei diferentes modelos de classificação (como *Random Forest* e *Logistic Regression*) para prever a ocorrência de chuvas na Austrália, realizando desde o pré-processamento dos dados até a extração de métricas de validação (Acurácia, F1-Score, Matriz de Confusão).

Tecnologias e Bibliotecas Utilizadas:

*   **Linguagem:** Python
*   **Manipulação e Análise de Dados:** Pandas, NumPy
*   **Machine Learning:** Scikit-Learn
*   **Visualização de Dados:** Matplotlib, Seaborn
